# RAG_ASSISTANT_API RAG Project

This repository contains a single focused project:

- `rag_assistant/` - a FastAPI-based PDF RAG backend using ChromaDB

Project files that matter:

- `rag_assistant/`
- `data/sample_generated.pdf`
- `.env` for local API keys
- `rag_env/` for your local virtual environment

Use `rag_assistant/README.md` for setup and run instructions.
